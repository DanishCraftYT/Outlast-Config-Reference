# Tools

## UPK Explorer
the UPK Explorer allows you to browse .upk files and make changes to them.<br>

### Requirements:
* [.NET 6.0 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/6.0)

### Downloads:
* [NexusMods](https://www.nexusmods.com/site/mods/587?tab=files)

### Creators:
* FCH823
* Wastelander121

## TFC Installer
the TFC Installer allows you to install UPK Explorer mods.<br>

### Requirements:
* [.NET 6.0 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/6.0)

### Downloads:
* [NexusMods](https://www.nexusmods.com/site/mods/588?tab=files)

### Creators:
* FCH823
* Wastelander121

## ME3 Explorer / Legendary Explorer
designed for the Mass Effect games but some of the versions also work with Outlast.<br>

## Texture Movie Editor
the Texture Movie Editor allows you to export and replace texture movies from Outlast 1.<br>

### Requirements:
* [UPK Explorer](https://www.nexusmods.com/site/mods/587?tab=files)
* [TFC Installer](https://www.nexusmods.com/site/mods/588?tab=files)
* [Bink Video Tools](https://www.radgametools.com/bnkdown.htm)

### Downloads:
* [Github](https://github.com/DanishCraftYT/TextureMovieEditor/releases)

### Tutorials:
* [how to modify MOVIES in OUTLAST! (OUTLAST MODDING EP4)](https://www.youtube.com/watch?v=kxuMIe_cb0U)
    * by Danish Craft

### Creators:
* Danish Craft
